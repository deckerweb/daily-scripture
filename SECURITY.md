# Security reporting

[Deutsch](SECURITY-de.md)

This documentation applies to Daily Scripture on single-site WordPress installations and websites in Multisite.

Please report suspected vulnerabilities privately through [GitHub’s vulnerability reporting form](https://github.com/deckerweb/daily-scripture/security/advisories/new). Do not publish exploit details in issues or discussions.

Include the Daily Scripture version, embedded component versions, WordPress/PHP versions, reproducible steps and possible impact. Do not send passwords, tokens, license keys or private customer data. Reports are reviewed confidentially; fixes and public disclosure are coordinated with the reporter. No response deadline is promised.

Use [issues](https://github.com/deckerweb/daily-scripture/issues) for ordinary bugs and [discussions](https://github.com/deckerweb/daily-scripture/discussions) for questions. Use the latest stable release when available; unpublished development copies are not stable releases.
